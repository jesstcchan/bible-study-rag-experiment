# Post-task evaluation button update

Copy both included files into the project's `bible_task` folder.

- After the Task 1 evaluation, the submit button says `Begin Task 2`.
- After the Task 2 evaluation, the submit button remains `Continue`.

The change does not alter stored data, randomization, or study conditions.
Restart oTree and use a new demo session to test both rounds. No database reset
is required.
